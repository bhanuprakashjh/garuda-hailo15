# Hailo-15L Perception Node — M0 (pipeline proven) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A C++ perception node on the Hailo-15L SBC runs camera → ISP → stock yolov8 detect, publishes v2 snapshots and JPEG frames over a local framed-TCP feed, and a Python-stdlib shim serves mono's HTTP contract on port 8098 so `garuda-portal` (unchanged) shows live detections from the board — with the first measured numbers in the benchlog.

**Architecture:** One `hailo_analytics` pipeline (media-library front end → `HailortAsyncStage` → `PostprocessStage` → app-sink callback) inside `garuda-perception`; the callback builds the snapshot JSON and pushes it, and a second app-sink JPEG-encodes the 1280×720 stream with libjpeg-turbo. Both go out on a framed TCP feed on 127.0.0.1; commands come in on a JSON-lines TCP socket. `garuda-mono-shim` (Python 3.10 stdlib) turns the feed into SSE + MJPEG + the POST endpoints. M0 has no tracker, no depth: track ids are per-frame indices, `lock`/`distance` are reported empty/invalid — the spec's M2 fills them.

**Tech Stack:** C++17, CMake 3.28, Yocto SDK `poky-glibc-x86_64-core-image-hailo-dev-armv8a-hailo15l-sbc-toolchain-4.0.23.sh` (target sysroot: HailoRT 5.3.0, `hailo_analytics` 1.12.0, media library 1.12.0, libjpeg-turbo 2.1.5), nlohmann/json (vendored single header, MIT), Python 3.10 stdlib on the board, Python 3.12 on the PC for tests.

**Spec:** `docs/superpowers/specs/2026-09-02-hailo15l-perception-node-design.md` (this plan implements milestone M0 of section 8; M1–M3 get their own plans).

**Spec amendment carried by this plan (section 3/4 of the spec):** the node→shim transport is **framed TCP on 127.0.0.1**, not ZeroMQ — the shim is stdlib-only and pyzmq is not on the board. ZeroMQ is dropped from v1 (YAGNI). Update the spec's wording in Task 12.

## Global Constraints

- Board: Hailo-15L SBC, stock image `vpu-stability-v1.12.0`, HailoRT 5.3.0, reached as `root@10.0.0.1` (key auth installed; PC profile `nmcli con up h15-link`). Nothing on the stock image is modified except `/opt/garuda/` and one init script.
- Snapshot schema is exactly `mono_state.build_snapshot` v2 (`hosts/pi5/mono_state.py`); boxes in **1280×720** pixels; `frame` = `{"width":1280,"height":720}`.
- Shim port **8098**; SSE throttled to **≤10 Hz**; MJPEG capped at **≤15 fps**.
- Feed: TCP `127.0.0.1:8971`, frame = 1 byte type (`S` snapshot JSON, `J` JPEG) + 4-byte big-endian length + payload. Commands: TCP `127.0.0.1:8972`, one JSON object per line, one JSON reply per line.
- Rule 1 (CLAUDE.md §6): no performance figure anywhere unless produced by a run on the board and written to `bench/benchlog.md` with a `bench/versions.md` snapshot.
- Rule 6: every new dependency states its licence in the commit; vendored `json.hpp` is MIT; libjpeg-turbo is IJG/BSD-3; the analytics framework and media library are Hailo proprietary SDK components used under the developer licence.
- Rule 3: `hosts/hailo15l/*.sh` are idempotent.
- Branch: `feat/hailo15l-perception` in a worktree (superpowers:using-git-worktrees) off `master` (which now holds the spec at `cad153c`).
- Never `pkill -f <pattern>` from a shell whose own command line contains `<pattern>`; on the board use `pkill -f "^camera-viewer-server"` style anchors (the 15-char `comm` truncation defeats `pkill -x` for long names).

```cpp
#include <nlohmann/json.hpp>

namespace garuda {
std::string build_snapshot_json(const SnapshotState& s) {
    using nlohmann::json;
    json tracks = json::array();
    for (const auto& t : s.tracks)
        tracks.push_back({{"id", t.id}, {"label", t.label}, {"conf", t.conf}, {"x", t.x}, {"y", t.y},
                          {"w", t.w}, {"h", t.h}, {"coasting", t.coasting}});
    json j = {
        {"v", 2},
        {"age_ms", s.age_ms ? json(*s.age_ms) : json(nullptr)},
        {"tracks", tracks},
        {"lock", {{"id", s.lock_id ? json(*s.lock_id) : json(nullptr)}, {"class", s.lock_class}, {"coasting", s.lock_coasting}}},
        {"distance", {{"raw_m", s.raw_m ? json(*s.raw_m) : json(nullptr)}, {"est_m", s.est_m ? json(*s.est_m) : json(nullptr)}, {"valid", s.valid}}},
        {"depth_engine", s.depth_engine},
        {"detector", {{"mode", s.detector_mode}, {"prompt", s.prompt}}},
        {"cal", {{"n", s.cal_n}, {"fit", s.cal_fit ? json(*s.cal_fit) : json(nullptr)}}},
        {"frame", {{"width", s.frame_w}, {"height", s.frame_h}}},
```

**Interfaces:**
- Produces:
  ```cpp
  namespace garuda {
  class FeedServer {                       // accepts any number of clients on 127.0.0.1:port; drops slow clients
  public:
      explicit FeedServer(uint16_t port);  ~FeedServer();
      void start(); void stop();
      void publish(char type, const std::string& payload);   // type 'S' or 'J'; non-blocking; thread-safe
      size_t client_count() const;
  };
  using CommandHandler = std::function<std::string(const std::string& request_json)>;  // returns reply JSON (one line)
  class CommandServer {
  public:
      CommandServer(uint16_t port, CommandHandler h);  ~CommandServer();
      void start(); void stop();
  };
  }
  ```
- Wire format (feed): `[type:1][len:4 big-endian][payload:len]`. Command: request line `\n`-terminated JSON; reply line `\n`-terminated JSON.

```cpp
static int listen_local(uint16_t port) {
    int fd = ::socket(AF_INET, SOCK_STREAM, 0); int one = 1;
    ::setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &one, sizeof one);
    sockaddr_in a{}; a.sin_family = AF_INET; a.sin_port = htons(port); a.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
    if (::bind(fd, (sockaddr*)&a, sizeof a) != 0 || ::listen(fd, 8) != 0) { ::close(fd); return -1; }
    return fd;
}
static int accept_with_timeout(int listen_fd, int ms) {
    pollfd p{listen_fd, POLLIN, 0}; if (::poll(&p, 1, ms) <= 0) return -1;
    return ::accept(listen_fd, nullptr, nullptr);

FeedServer::FeedServer(uint16_t port) : m_port(port) {}
FeedServer::~FeedServer() { stop(); }
void FeedServer::start() {
    m_listen_fd = listen_local(m_port); if (m_listen_fd < 0) throw std::runtime_error("FeedServer: bind failed on port " + std::to_string(m_port));
    m_running = true; m_thread = std::thread([this] { accept_loop(); });
}
void FeedServer::stop() {
    if (!m_running.exchange(false)) return;
    if (m_thread.joinable()) m_thread.join();
    std::lock_guard<std::mutex> g(m_mu); for (int c : m_clients) ::close(c); m_clients.clear();
    if (m_listen_fd >= 0) { ::close(m_listen_fd); m_listen_fd = -1; }
}
void FeedServer::accept_loop() {
    while (m_running) {
        int c = accept_with_timeout(m_listen_fd, 100); if (c < 0) continue;
        int one = 1; ::setsockopt(c, IPPROTO_TCP, TCP_NODELAY, &one, sizeof one);
        timeval tv{0, 200000}; ::setsockopt(c, SOL_SOCKET, SO_SNDTIMEO, &tv, sizeof tv);   // slow client => drop
        std::lock_guard<std::mutex> g(m_mu); m_clients.push_back(c);
    }
}
void FeedServer::publish(char type, const std::string& payload) {
    uint32_t len_be = htonl((uint32_t)payload.size());
    std::string frame; frame.reserve(5 + payload.size()); frame.push_back(type); frame.append((char*)&len_be, 4); frame.append(payload);
    std::lock_guard<std::mutex> g(m_mu);
    for (auto it = m_clients.begin(); it != m_clients.end();) {
        ssize_t n = ::send(*it, frame.data(), frame.size(), MSG_NOSIGNAL);
        if (n != (ssize_t)frame.size()) { ::close(*it); it = m_clients.erase(it); } else ++it;
    }
}

}
void CommandServer::accept_loop() {
    while (m_running) { int c = accept_with_timeout(m_listen_fd, 100); if (c >= 0) std::thread([this, c] { serve(c); }).detach(); }
}
void CommandServer::serve(int fd) {
    std::string acc; char buf[4096];
    while (m_running) {
        pollfd p{fd, POLLIN, 0}; if (::poll(&p, 1, 200) <= 0) continue;
        ssize_t n = ::read(fd, buf, sizeof buf); if (n <= 0) break;
        acc.append(buf, n); size_t nl;
        while ((nl = acc.find('\n')) != std::string::npos) {
            std::string line = acc.substr(0, nl); acc.erase(0, nl + 1);
            std::string reply = m_handler(line) + "\n";
            if (::send(fd, reply.data(), reply.size(), MSG_NOSIGNAL) != (ssize_t)reply.size()) { ::close(fd); return; }
        }
    }
    ::close(fd);
}
```

```cpp
namespace garuda {
JpegEncoder::JpegEncoder(int quality) : m_handle(tjInitCompress()), m_quality(quality) {
    if (!m_handle) throw std::runtime_error("tjInitCompress failed");
}
JpegEncoder::~JpegEncoder() { if (m_handle) tjDestroy((tjhandle)m_handle); }

std::vector<unsigned char> JpegEncoder::encode_nv12(const unsigned char* y, int y_stride, const unsigned char* uv, int uv_stride, int width, int height) {
    // TurboJPEG wants planar I420: de-interleave NV12's UV plane into U and V.
    const int cw = (width + 1) / 2, ch = (height + 1) / 2;
    m_u.resize((size_t)cw * ch); m_v.resize((size_t)cw * ch);
    for (int r = 0; r < ch; ++r) {
        const unsigned char* src = uv + (size_t)r * uv_stride; unsigned char* du = m_u.data() + (size_t)r * cw; unsigned char* dv = m_v.data() + (size_t)r * cw;
        for (int c = 0; c < cw; ++c) { du[c] = src[2 * c]; dv[c] = src[2 * c + 1]; }
    }
    const unsigned char* planes[3] = {y, m_u.data(), m_v.data()};
    int strides[3] = {y_stride, cw, cw};
    unsigned char* out = nullptr; unsigned long out_size = 0;
    int rc = tjCompressFromYUVPlanes((tjhandle)m_handle, planes, width, strides, height, TJSAMP_420, &out, &out_size, m_quality, TJFLAG_FASTDCT);
    if (rc != 0) { if (out) tjFree(out); throw std::runtime_error(std::string("tjCompressFromYUVPlanes: ") + tjGetErrorStr2((tjhandle)m_handle)); }
    std::vector<unsigned char> jpg(out, out + out_size); tjFree(out); return jpg;
}
```

```cpp
            std::lock_guard<std::mutex> g(state.mu);
            s.lock_class = state.target_class;

                auto [px, py] = *state.pending_lock_point; state.pending_lock_point.reset();

      .connect_frontend("frontend", cfg["jpeg_stream"], "jpg_sink");
```

```python
#!/usr/bin/env python3
"""garuda-mono-shim: presents garuda-mono's HTTP contract (port 8098) on top of garuda-perception's local feed.
Standard library only (the board has no numpy/pyzmq). See docs/superpowers/specs/2026-09-02-hailo15l-perception-node-design.md §4.
"""
import argparse, json, socket, struct, threading, time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import parse_qs, urlparse

SSE_MAX_HZ = 10.0
MJPEG_MAX_FPS = 15.0
INDEX_HTML = b"""<!doctype html><title>garuda-mono-shim</title><body style="font-family:monospace;background:#111;color:#ddd">
<img src="/stream" style="max-width:100%"><pre id="s"></pre><script>
const es=new EventSource('/api/events');es.onmessage=e=>{document.getElementById('s').textContent=JSON.stringify(JSON.parse(e.data),null,1)}
</script></body>"""

class Feed:
    """Reconnecting reader of the framed feed; keeps the latest snapshot and JPEG."""
    def __init__(self, host, port):
        self.host, self.port = host, port; self.lock = threading.Lock(); self.cv = threading.Condition(self.lock)
        self.snap = None; self.snap_seq = 0; self.jpeg = None; self.jpeg_seq = 0
        threading.Thread(target=self._run, daemon=True).start()
    def _run(self):
        while True:
            try:
                with socket.create_connection((self.host, self.port), timeout=5) as s:
                    s.settimeout(None)
                    while True:
                        t = s.recv(1, socket.MSG_WAITALL); hdr = s.recv(4, socket.MSG_WAITALL)
                        if len(t) != 1 or len(hdr) != 4: break
                        ln = struct.unpack(">I", hdr)[0]; p = s.recv(ln, socket.MSG_WAITALL)
                        if len(p) != ln: break
                        with self.cv:
                            if t == b"S": self.snap = p; self.snap_seq += 1
                            elif t == b"J": self.jpeg = p; self.jpeg_seq += 1
                            self.cv.notify_all()
            except OSError:
                pass
            time.sleep(0.5)
    def wait_snap(self, seen, timeout=1.0):
        with self.cv:
            self.cv.wait_for(lambda: self.snap_seq != seen, timeout); return self.snap, self.snap_seq
    def wait_jpeg(self, seen, timeout=1.0):
        with self.cv:
            self.cv.wait_for(lambda: self.jpeg_seq != seen, timeout); return self.jpeg, self.jpeg_seq

class Commands:
    def __init__(self, host, port): self.host, self.port = host, port; self.lock = threading.Lock(); self.sock = None
    def call(self, obj):
        with self.lock:
            for attempt in (1, 2):
                try:
                    if self.sock is None: self.sock = socket.create_connection((self.host, self.port), timeout=3)
                    self.sock.sendall((json.dumps(obj) + "\n").encode()); f = self.sock.makefile("r"); line = f.readline()
                    if not line: raise OSError("closed")
                    return json.loads(line)
                except OSError:
                    try: self.sock.close()
                    except Exception: pass
                    self.sock = None
                    if attempt == 2: return {"ok": False, "error": "node unreachable"}

POST_MAP = {  # path -> (cmd, {query key: (json key, type)})
    "/api/mono_click": ("lock_point", {"x": ("x", float), "y": ("y", float)}),
    "/api/mono_target": ("target", {"class": ("class", str)}),
    "/api/mono_calibrate": ("cal_add", {"true_m": ("true_m", float)}),
    "/api/mono_calibrate_reset": ("cal_reset", {}),
    "/api/detector": ("detector", {"mode": ("mode", str)}),
    "/api/depth_engine": ("depth_engine", {"engine": ("engine", str)}),
}

def make_handler(feed, cmds):
    class H(BaseHTTPRequestHandler):
        protocol_version = "HTTP/1.1"
        def log_message(self, *a): pass
        def _json(self, code, body):
            b = body if isinstance(body, bytes) else json.dumps(body).encode()
            self.send_response(code); self.send_header("Content-Type", "application/json"); self.send_header("Content-Length", str(len(b)))
            self.send_header("Access-Control-Allow-Origin", "*"); self.end_headers(); self.wfile.write(b)
        def do_GET(self):
            p = urlparse(self.path).path
            if p == "/": self.send_response(200); self.send_header("Content-Type", "text/html"); self.send_header("Content-Length", str(len(INDEX_HTML))); self.end_headers(); self.wfile.write(INDEX_HTML); return
            if p == "/api/state":
                return self._json(200, feed.snap or b'{"v":2,"tracks":[],"error":"no snapshot yet"}')
            if p == "/api/events":
                self.send_response(200); self.send_header("Content-Type", "text/event-stream"); self.send_header("Cache-Control", "no-cache")
                self.send_header("Access-Control-Allow-Origin", "*"); self.end_headers()
                seen = 0; min_gap = 1.0 / SSE_MAX_HZ; last = 0.0
                try:
                    while True:
                        snap, seen = feed.wait_snap(seen, timeout=1.0)
                        if snap is None: self.wfile.write(b": keepalive\n\n"); self.wfile.flush(); continue
                        gap = time.monotonic() - last
                        if gap < min_gap: time.sleep(min_gap - gap)
                        self.wfile.write(b"data: " + snap + b"\n\n"); self.wfile.flush(); last = time.monotonic()
                except (BrokenPipeError, ConnectionResetError): return
            if p == "/stream":
                self.send_response(200); self.send_header("Content-Type", "multipart/x-mixed-replace; boundary=frame"); self.end_headers()
                seen = 0; min_gap = 1.0 / MJPEG_MAX_FPS; last = 0.0
                try:
                    while True:
                        jpg, seen = feed.wait_jpeg(seen, timeout=1.0)
                        if jpg is None: continue
                        gap = time.monotonic() - last
                        if gap < min_gap: time.sleep(min_gap - gap)
                        self.wfile.write(b"--frame\r\nContent-Type: image/jpeg\r\nContent-Length: " + str(len(jpg)).encode() + b"\r\n\r\n" + jpg + b"\r\n"); self.wfile.flush(); last = time.monotonic()
                except (BrokenPipeError, ConnectionResetError): return
            self._json(404, {"error": "not found"})
        def do_POST(self):
            u = urlparse(self.path); q = parse_qs(u.query)
            if u.path not in POST_MAP: return self._json(404, {"error": "not found"})
            cmd, spec = POST_MAP[u.path]; obj = {"cmd": cmd}
            for qk, (jk, typ) in spec.items():
                if qk in q: obj[jk] = typ(q[qk][0])
            rep = cmds.call(obj)
            if rep.get("ok"): return self._json(200, rep)
            code = 501 if cmd in ("detector", "depth_engine", "cal_add") else 400
            return self._json(code, rep)
    return H

def main():
    ap = argparse.ArgumentParser(); ap.add_argument("--feed", default="127.0.0.1:8971"); ap.add_argument("--cmd", default="127.0.0.1:8972"); ap.add_argument("--port", type=int, default=8098)
    a = ap.parse_args(); fh, fp = a.feed.split(":"); ch, cp = a.cmd.split(":")
    srv = ThreadingHTTPServer(("0.0.0.0", a.port), make_handler(Feed(fh, int(fp)), Commands(ch, int(cp)))); srv.daemon_threads = True
    print(f"garuda-mono-shim on :{a.port} (feed {a.feed}, cmd {a.cmd})", flush=True); srv.serve_forever()

if __name__ == "__main__": main()
```

- [ ] **Step 1: Init script**

`hosts/hailo15l/garuda-perception.init`:
```sh
#!/bin/sh
### BEGIN INIT INFO
# Provides:          garuda-perception
# Required-Start:    isp_media_server
# Default-Start:     5
# Default-Stop:      0 1 6
### END INIT INFO
# garuda-perception + garuda-mono-shim. Waits for the ISP media server (it can lose the boot-time OOM race).
export HAILO_MEDIA_LIB_SKIP_METADATA_CONFIG_VALIDATION=1
NODE=/opt/garuda/bin/garuda-perception; SHIM=/opt/garuda/bin/garuda_mono_shim.py; CFG=/opt/garuda/perception.json
NODE_PID=/var/run/garuda-perception.pid; SHIM_PID=/var/run/garuda-mono-shim.pid; LOG=/var/log/garuda-perception.log

wait_isp() {
  i=0
  while [ $i -lt 30 ]; do
    pgrep -f "^/usr/bin/isp_media_server" >/dev/null && return 0
    [ $i -eq 5 ] && { echo "$(date) isp_media_server absent, restarting it" >> $LOG; /etc/init.d/isp_media_server restart >> $LOG 2>&1; }
    i=$((i+1)); sleep 1
  done
  echo "$(date) isp_media_server never appeared" >> $LOG; return 1
}
start() {
  [ -f $NODE_PID ] && kill -0 "$(cat $NODE_PID)" 2>/dev/null && { echo "already running"; return 0; }
  wait_isp || return 1
  cd /opt/garuda && start-stop-daemon -S -b -m -p $NODE_PID -x $NODE -- --config $CFG >> $LOG 2>&1
  sleep 2
  start-stop-daemon -S -b -m -p $SHIM_PID -x /usr/bin/python3 -- $SHIM >> $LOG 2>&1
  echo "garuda-perception started"
}
stop() {
  for p in $SHIM_PID $NODE_PID; do [ -f $p ] && { start-stop-daemon -K -p $p -R 5 2>/dev/null; rm -f $p; }; done
  echo "garuda-perception stopped"
}
case "$1" in
  start) start ;; stop) stop ;; restart) stop; sleep 1; start ;;
  status) for p in $NODE_PID $SHIM_PID; do [ -f $p ] && kill -0 "$(cat $p)" 2>/dev/null && echo "$p running" || echo "$p stopped"; done ;;
  *) echo "Usage: $0 {start|stop|restart|status}"; exit 1 ;;
esac
```
