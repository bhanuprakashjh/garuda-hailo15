Depth · CamArray stereo (OV9281)

Live stereo depth with a switchable engine — pick SGBM (CPU, true metric cm), StereoNet, fast_depth, or scdepthv3 from the buttons below. Runs as the garuda-depth service on the CamArray, so it runs alongside the CM3 follow feed. Compute pauses when you leave this tab.

Bench experiment. The NPU models StereoNet/scdepthv3 are EVAL-ONLY by licence (see models/LICENCES.md) — never shipped; SGBM is the licence-clean metric engine.

Target Range · OV9281 stereo (metric)

Click a detected object in the view (or pick a class) to lock it — its distance is triangulated from the left/right pair on the NPU (a real measurement, not a size guess). Standalone: the CM3 Inference feed shares the one NPU, so stop it before ranging. Compute pauses when you leave this tab.

Mono Depth · single colour camera (CM3 + DepthAnything)

Experimental single-camera distance: CM3 colour → yolov11m detect + DepthAnything relative depth (one NPU process). DepthAnything is relative, so calibrate it to metres — stand at a known distance, type it, click Add cal point (2+ points fits the scale); then the estimate tracks you live. Shares the NPU with the stereo tab — don't run both at once.
